# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub private vulnerability reporting:
go to the [Security tab](https://github.com/drophawk-net/drophawk-js/security) of this repository and choose "Report a vulnerability".

Do not open a public issue or pull request for a vulnerability.
We aim to acknowledge a report within three working days.

## Scope

This policy covers the packages in this repository, `@drophawk/sdk` and `@drophawk/mcp`, and the workflows that build and publish them.
Problems in the DropHawk service itself can be reported the same way.

## Supported versions

Only the latest published version of each package receives security fixes.
